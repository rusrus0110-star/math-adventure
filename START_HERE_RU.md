# Math Adventure — локальный запуск

## 1. Распакуй проект

Архив уже содержит готовую структуру Vite/React/TypeScript.

## 2. Проверь Node.js

Нужен Node.js 20.19+; Node 22 LTS подходит.

```bash
node -v
npm -v
```

## 3. Установи зависимости

```bash
npm install
```

## 4. Запусти development server

```bash
npm run dev
```

Открой адрес, который покажет Vite.

## 5. Что уже реализовано

- немецкий интерфейс;
- локальные профили игроков без авторизации;
- `playerId` во всех пользовательских данных;
- 5 уровней со сложением и вычитанием;
- 10 заданий за игровую сессию;
- 4 варианта ответа;
- score за правильность, скорость и streak;
- 7 звёзд за точность;
- монеты;
- разблокировка следующего уровня;
- сохранение прогресса в IndexedDB;
- атомарное сохранение завершённой игровой сессии;
- экран прогресса;
- PWA-конфигурация;
- персонаж Mia с аксессуарами;
- активные дни, недельные цели и суперпризы;
- отдельные экраны ребёнка и родителей;
- Repository interfaces для будущего API/backend.

## 6. Что пока намеренно упрощено

- данные хранятся только в этом браузере; удаление данных сайта удалит прогресс;
- adaptive learning ещё не подключён к игровому циклу;
- нет backend и cloud sync;
- нет авторизации;
- нет звуков;
- нет умножения/деления.


## 8. Архитектура

Подробно смотри:

```text
docs/ARCHITECTURE.md
```

Главная идея:

```text
React UI
   ↓
Application use cases
   ↓
Domain rules
   ↓
Repository ports
   ↓
IndexedDB adapter сейчас
API adapter позже
```

Поэтому добавление Node.js/PostgreSQL позже не должно требовать переписывания game engine.

Актуальные правила монет, звёзд и миграции описаны в README.md и docs/ARCHITECTURE.md.
